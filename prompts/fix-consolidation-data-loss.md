## Do NOT relitigate (settled — re-opening these burns an iteration)

1. **Rejected: make consolidation preserve bodies.** `MAX_CONSOLIDATED_VALUE_LENGTH`
   (consolidation.py:44) == `MAX_VALUE_LENGTH` (models.py:126) == 4096, and profile
   `limits.max_value_length` can only *lower* the cap (store.py:1523 applies it only
   when `< MAX_VALUE_LENGTH`). A lossless merge is not expressible. Do not raise
   either constant.

   competing entries in recall — the duplication consolidation exists to prevent.
3. The same-topic check is **AND-gated** with the threshold, not deleted and not
   replaced. Same-topic remains a necessary condition; it stops being a sufficient one.
4. Preservation floor = **0.6**. `exempt_tiers` default = **`["architectural"]`**.
5. `source="user"` is an **input alias only**. The stored canonical value stays
   `human`; `MemorySource` stays four-valued.
6. **No migrations in this work.** Nothing here touches `src/tapps_brain/migrations/`,
