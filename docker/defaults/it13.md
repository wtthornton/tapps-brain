# IT13 workstation profile

**Host:** `it13` (reviewed 2026-06-09)  
**Role:** Single-machine lab — IDE coding, tapps-brain development, pytest, AgentForge POC.  
**Not for:** Production runtime / many-tenant AgentForge (use `quality.env` on a separate stack + DB).

---

## Posture summary

| Item | IT13 choice | Rationale |
|------|-------------|-----------|
| Tier file | `docker/defaults/it13.env` | Extends **balanced** with offline embeddings + IT13 topology |
| Brain count | **One** (`tapps-brain` compose project) | Coding + POC share brain; dev/test memory stays on separate Postgres |
| MCP profile | `coder` (client + server default) | IDE + tapps-mcp bridge; not `full` on this host |
| Idempotency / per-tenant auth | **Off** | Solo dev + shared token; enable on a future runtime stack |
| OTel | **Off** (Jaeger exists for AgentForge only) | Turn on only when OTLP endpoint is wired |
| Embeddings | `REQUIRED=1`, `MODEL_OFFLINE=1` | `tapps-brain-hfcache` volume is persisted on this box |

Reviewed `tapps-brain-http`, `tapps-brain-db`, `agentforge-main` (24h window).

### Brain HTTP

- **Healthy:** `/healthz`, `/ready`, live smoke 5/5, MCP auth 401 without token.
- **Repeated embedding model loads** on many `CallToolRequest` lines (`Loading SentenceTransformer … BAAI/bge-small-en-v1.5`). After redeploy, watch logs; persistent reload-per-request suggests worker lifecycle issue — not fixed by tier alone.

## Apply IT13 profile

### New stack

```bash
cp docker/.env.example docker/.env
# Fill REPLACE_ME_* secrets and TAPPS_BRAIN_ALLOWED_ORIGINS (required for strict mode)
make brain-env-init TIER=it13
make hive-deploy
make brain-smoke-live
```

### Replace existing tier block

`docker/.env` allows only one tier block. Remove lines from `TAPPS_BRAIN_TIER=` through `TAPPS_BRAIN_DEFAULT_PROFILE=`, then:

```bash
cat docker/defaults/it13.env >> docker/.env
make dev-deploy
```

Verify container picked up tier vars:

```bash
docker inspect tapps-brain-http --format '{{range .Config.Env}}{{println .}}{{end}}' \
  | grep -E 'TIER|IDEMPOTENCY|OTEL|OFFLINE|DEFAULT_PROFILE'
make brain-smoke-live   # uses agent_brain for /v1/experience write, coder for query
make brain-healthcheck  # expect coder → 21 tools in tools/list
```

## IT13 maintenance checklist

Run periodically on this workstation:

```bash
# Reclaim Docker build cache (was ~472 GiB reclaimable)
docker builder prune -f

# Remove leftover AgentForge test Postgres (if present)
docker rm -f $(docker ps -aq --filter name=af-test-pg-) 2>/dev/null || true

# Redeploy brain after compose/tier changes
make dev-deploy && make brain-smoke-live
```

Ensure `docker/.env` has **one** `TAPPS_BRAIN_EMBEDDING_MODEL_OFFLINE` line (duplicate keys caused `OFFLINE=1` vs tier `0` confusion).

Set `TAPPS_BRAIN_METRICS_TOKEN` (see `docker/.env.example`) so `/metrics` requires `Authorization: Bearer <token>`.

## When to leave IT13 profile

| Goal | Action |
|------|--------|
| Production / many AgentForge projects | New host or `tapps-brain-runtime` stack + `quality.env` + DB `tapps_brain_runtime` |
| Minimal throwaway brain | `cheap.env` |
| Generic coding default (any dev laptop) | `balanced.env` |
| Rehearse OTel on IT13 | Uncomment OTel block in `it13.env`, set OTLP to Jaeger, recreate container |
